# Workspace Project Rules — OrderChinaViet Logistics Management Platform

1. **No Emojis**: Do NOT use emojis anywhere in the user interface, headers, labels, buttons, or console log statements. Use crisp SVG icons from `lucide-react` instead.
2. **Font Weight Constraint**: Do NOT use `font-extrabold` (800 weight). The maximum font weight allowed is `font-bold` (700 weight) or `font-semibold` (600 weight).
3. **Global Font Family**: The entire website must strictly use `font-family: Inter, Inter Fallback, -apple-system, BlinkMacSystemFont, sans-serif;`.
4. **No font-sans Class**: Do NOT use the `font-sans` Tailwind utility class anywhere in the user interface or code. The font family is already globally declared.
